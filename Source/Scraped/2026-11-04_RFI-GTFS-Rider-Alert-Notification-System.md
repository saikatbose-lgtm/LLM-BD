## Description

GoTriangle is exploring options that utilize each agencies GTFS and “bundles” them all into a single data integration (Static and/or Real-Time). This allows alerts to be issued by way of emailing subscribers via a connected database by agency and route (Existing), push notifying applications such as google maps, Apple maps, Transit App, UMO, etc., and has the ability to be embed on our websites (Wordpress).
