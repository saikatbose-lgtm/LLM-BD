## Description

Burke County Public Schools is seeking comprehensive, competitive proposals from qualified Audio-Visual (AV) Integration Firms to design, program, and install a hybrid boardroom technology refresh. The objective of this project is to update the existing Board Room into a high-performance, multi-platform hybrid environment that is ready for Microsoft Teams, Zoom, and Google Meet and can stream meetings live to YouTube while a conference is in progress.
