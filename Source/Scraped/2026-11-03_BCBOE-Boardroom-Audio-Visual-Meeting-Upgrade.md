## Description

Burke County Public Schools is seeking comprehensive, competitive proposals from qualified Audio-Visual (AV) Integration Firms to design, program, and install a hybrid boardroom technology refresh. The objective of this project is to update the existing Board Room into a high-performance, multi-platform hybrid environment that is ready for Microsoft Teams, Zoom, and Google Meet and can stream meetings live to YouTube while a conference is in progress. The final system must deliver a seamless user experience prioritizing meeting equity for remote participants, flawless local speech reinforcement (voice lift), centralized administrator control, and flexible operational capabilities via an optional wireless remote control position, and public access to meetings through live streaming.
