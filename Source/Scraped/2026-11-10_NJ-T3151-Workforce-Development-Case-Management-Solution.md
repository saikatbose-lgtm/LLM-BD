## Description

The State of New Jersey, Division of Purchase and Property, issued RFP T3151 for a "Workforce Development Case Management Solution." The solicitation is tied to NJ Workforce Modernization requirements (Appendix A), the NJ Workforce Program (Appendix B), the NJ AOSOS Application (Appendix C), and an Interface Reference Document (Appendix D), indicating the procurement of a software/application solution — including web/mobile application development and server-based application software/hosting (per the listed NIGP codes) — to support case management for New Jersey's workforce programs. Contract term runs 07/01/2027 through 06/30/2034. A 15% performance bond is required; the set-aside category is SBE and DVOB Sub-Contracting.

## Relevance

Matched: The underlying scope is the design/provision of an IT software solution (a case-management application, including web/mobile application development and server/ASP-hosted application software per the associated NIGP codes 208-45, 208-54, 209-13, 209-46, 209-54, 920-03, 920-04). This falls squarely under "Information Technology," "Programming Services, Computer (Including Mobile Device Applications)," and "Data Processing Services" in the approved keyword list — it is a genuine IT systems-development procurement, not an incidental keyword mention.
