## Description

HHSC solicitation titled "FY27 DSCSA Compliance Subscription." DSCSA refers to the federal Drug Supply Chain Security Act, which governs pharmaceutical product tracing/serialization. The ESBD listing description field contains only the title itself ("DSCSA Compliance Subscription"); the full scope is in attached documents (IFB_HHS0018074.pdf and an Exhibits zip) that were not opened.

## Relevance

**Matched (unconfirmed).** A "subscription" to a regulatory "compliance" system for drug-supply-chain tracing is, by its nature, almost always procurement of access to a SaaS/software platform that ingests and processes drug-transaction tracing data — which would fall under "Software Maintenance/Support" and/or "Data Processing Services." However, the only NIGP code published on the listing page ("Infrastructure and Infrastructure Improvements") is generic and does not itself confirm an IT/software scope, and the full IFB/exhibit attachments (which would state the actual deliverable) were not reviewed.
